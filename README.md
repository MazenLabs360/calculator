Calculator

A simple desktop calculator application built with C# and Windows Forms using .NET Framework 4.7.2.

Overview

Calculator is a Windows desktop application that provides a graphical interface for performing basic arithmetic operations. Users enter numbers through on-screen buttons, choose an operation, and view the calculated result.

Features

- Number input using buttons 0–9
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Result calculation (=)
- Clear/reset (C)
- Continue using the previous result
- Run/stop controls

Built With

- C#
- Windows Forms
- .NET Framework 4.7.2
- Visual Studio

Project Structure

- "calculator.sln" – Solution file
- "calculator.csproj" – Project configuration
- "Program.cs" – Application entry point
- "Form1.cs" – Calculator logic
- "Form1.Designer.cs" – User interface design
- "Properties/" – Application resources and settings

Requirements

- Windows
- Visual Studio
- .NET Framework 4.7.2

Getting Started

1. Clone or download this repository.
2. Open "calculator.sln" in Visual Studio.
3. Build the solution.
4. Run the application using F5.
